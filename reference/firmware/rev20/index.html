Mbox Firmware Updater Rev 20 (OS X application)

Mac Bin-Hex (.hqx) file, requires Stuffit Expander 5.1.2 or higher (included with Mac OS X).

This installs the exact same Firmware Rev 20 as the OS 9 application below, but will run when booted in OS X.

What is Included in This Download?

  • Mbox Updater OSX.rev20
  • Mbox Firmware rev20 Read Me.rtf

What Does This File Do?

This software will update your Mbox firmware to version 20, required for OS X. In most cases, your Mbox will have firmware 20 already, in which case the Firmware update will report that no changes have been made.

How Do I Use It?

  1. Pro Tools LE 6.0 or 6.0.1 must be already installed in order for the driver to recognize the Mbox.
  2. Quit the Pro Tools application if it is open.
  3. Download Mbox Firmware Updater Rev 20 from the link above.
  4. If the file does not automatically expand when downloaded, expand it using Aladdin Expander.
  5. Plug the Mbox into your computer's USB port.
  6. Double-Click the application: Mbox Updater OSX.rev20
  7. Follow the on-screen instructions.

Note: Apple System Profiler in OS X will not identify the Firmware version installed on your Mbox. If you are having difficulty getting your Mbox recognized with Pro Tools LE 6 in OS X, and you do not have OS 9 to run the Firmware updater below, use this version in OS X to update your Mbox firmware.

Who Should Use This?

All Mbox users.

How To Identify Your Mbox Firmware Version

  1. Plug the Mbox USB cable to your computer's USB port.
  2. Open Apple System Profiler from your Apple Menu.
  3. Choose the tab that says Devices and Volumes.
  4. Click open the arrow next to Mbox on USB 0 or USB 1.
  5. Look for the Release number, which indicates the firmware version.
  6. If it says 0.2, then it is already Mbox firmware rev 20.
  7. If it says 0.1.6, 0.1.8, or 0.1.9 then it can be updated with this downloadable Mbox Firmware Updater Rev 20.

What Does This File Do?

This software will update your Mbox firmware to version 20.

This Firmware Version Resolves the Following Issues:

  1. Fixes a problem with S/PDIF transfers from Mbox S/PDIF output to older S/PDIF devices at 48 kHz that could not lock to the S/PDIF clock from Mbox.

  2. Alleviates some cases where Mbox is not seen on the USB bus when plugged in or the computer is booted (USB light on Mbox fails to light).

  3. The input select lights on Channel 1 & 2 sometimes bounce around when selecting the input select switch.

How Do I Use It?

  1. Pro Tools LE 5.2 or 5.2.1 must be already installed in order for the driver to recognize the Mbox.
  2. Quit the Pro Tools application if it is open.
  3. Download Mbox Firmware Updater Rev 20 from the link above.
  4. If the file does not automatically expand when downloaded, expand it using Aladdin Expander.
  5. Plug the Mbox into your computer's USB port.
  6. Double-Click the application: MBoxFirmwareUpdater.rev20
  7. Follow the on-screen instructions.

Digidesign USB Driver
202 k

Digidesign Mbox USB Driver Update v.1.0.1 For Pro Tools LE (Mac) v.5.2 & 5.2.1

Note: Neither the Pro Tools LE 5.2 CD that originally shipped with Mbox or the download of Pro Tools LE (Mac) v.5.2.1 available at www.DigiProNet.com include this updated USB Driver. This driver will be included with the next revision of Pro Tools LE v5.2.1 CDs included with retail Mbox packages.

What's Fixed with USB Driver v1.0.1?

The USB Driver Update fixes a problem that could result in corrupted audio recordings. Typically, the recorded audio would contain clicks and pops after long periods of recording time. Digidesign recommends that all Mbox users replace their "Digidesign USB Driver" version 1.0 (located in the System Folder /Extensions Folder) with this version 1.0.1 driver.

Who Should Use this Update?

All Mbox Users

What's Included in this Download?

  • Digidesign USB Driver (version 1.0.1)
  • USB Driver 1.0.1 Read Me.pdf (with the text from this page)

Updating the Digidesign USB Driver for Mbox

  1. Download the Digidesign USB Driver version 1.0.1 from the link above
  2. If the download does not automatically expand, use Stuffit Expander version 5.1.2 or higher to expand. The expanded folder will be named "Digidesign USB Driver v1.0.1".
  3. Quit Pro Tools LE or any other audio application currently accessing Mbox.
  4. Unplug the USB cable from Mbox
  5. Place the new Digidesign USB Driver v1.0.1 in the Extensions Folder inside the System Folder.
  6. Click "OK" when prompted to replace the current file. (it is not necessary to restart your computer)
  7. Reconnect the USB cable to Mbox.
  8. Once the "USB" LED on the front of the unit is lit, re-launch Pro Tools and continue working. If the USB LED does not light, unplug and then replug the USB cable back into the computer.
